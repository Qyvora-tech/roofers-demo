# TIMBER & PEAK ROOFING CO. — Master Architectural Roofing Website (USA Demo)

A website designed specifically for elite roofing contractors in the United States. Built with **React**, **Vite**, **Tailwind CSS**, and **Framer Motion**, featuring a **woody color scheme** (smoked oak, aged cedar, rich walnut, and burnished copper accents).

---

## 🚀 How to Run Locally

```bash
# 1. Install dependencies
npm install

# 2. Start Vite development server
npm run dev
```

Visit: `http://localhost:3000/`

---

## 📦 How to Deploy for Live Pitching

To deploy this demo with a free shareable link to send to US roofing clients:

### Deploy to Vercel (Recommended):
```bash
npm install -g vercel
vercel
```

### Or Deploy to Netlify:
```bash
npm run build
# Drag and drop the /dist folder directly into app.netlify.com/drop
```
